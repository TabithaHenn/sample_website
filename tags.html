Important HTML tags

This page is designed as a quick reference for some of the common tags covered in Learn Enough HTML to Be Dangerous. In the process of making it, we'll learn how to make HTML tables via table and related tags.

The tables below don't include all HTML tags, but they do list many of the most important ones.

Block Elements

Tag Name Purpose Example Result
h1–h6 headings include a heading (levels 1–6)
table table include a table
tr table row include a row of data
th table header make a table header
td table data include a table data cell
div division defines a division or a section in an HTML document <div><p>This is some text in a div element.</p></div>

This is some text in a div element.
header header label the page header <header>...</header>
...
ol ordered list list elements in numerical order 
<ol>
	1. Let them come
	2. Let them be
	3. Let them go
	4. Focus on your system
</ol>
  1. Let them come
  2. Let them be
  3. Let them go
  4. Focus on your system
ul unordered list list elements whose order doesn’t matter 
<ul>
	•sushi
	•pasta
	•eggs
</ul>
  • sushi
  • pasta
  • eggs
li list include a list item (ordered or unordered) <li>random</li>
  • random
    		•
    blockquote block quotation show formatted quotation
    br break make a new line

    Inline Elements

    Tag Name Purpose Example Result
    em emphasized make emphasized text <em>technical sophistication</em> technical sophistication
    strong strong make strong text <strong>at least a billion people</strong> at least a billion people
    a anchor make hyperlink <a href="http://learnenough.com/">Learn Enough</a> Learn Enough
    img image include an image <img src="http://bit.ly/1MZAFuQ" alt="Michael Hartl">
    code code define text as code <code>displayed in the browser's default monospace font</code> displayed in the browser's default monospace font
    span span define inline section in document <p>My mother has <span style="color: blue">blue</span> eyes.</p>

    My mother has blue eyes.

    Document Tags

    Tag Name Purpose Example Result
    html hypertext markup language represent the root of an HTML document <html lang="en">this is the root</html> this is the root
    head head container for metadata <head>metadata</head> metadata
    body body define the document's body <body>all the contents of an HTML document</body> all the contents of an HTML document
    meta metadata define metadata about an HTML document <meta charset="utf-8">
